# RDDD Screen Design

화면 설계 문서와 구현 가능한 수준의 UI 와이어프레임을 일관된 형식으로 만드는 Codex 스킬입니다.

스크린샷, UI 코드, 제품 요구사항을 바탕으로 화면 구조를 SVG로 시각화하고, 번호가 매겨진 콜아웃과 설명 표를 함께 작성합니다.

## 주요 기능

- 주요 영역을 보여주는 화면 개요 와이어프레임 작성
- 폼, 컨트롤, 상태 등 특정 영역을 확대한 상세 와이어프레임 작성
- 정상, 경고, 오류, 로딩, 빈 상태, 비활성 상태 비교
- SVG 내부의 일관된 디자인 토큰과 빨간색 번호 콜아웃 사용
- 모든 콜아웃을 UI 개념과 연결하는 설명 표 작성
- 사용자에게 표시되는 정확한 레이블과 메시지 정리
- 와이어프레임 SVG의 기본 유효성 검증

## 사용 시점

다음과 같은 작업에서 사용합니다.

- 새로운 화면의 요구사항을 화면 설계서로 정리할 때
- 기존 UI를 개편하기 전에 구조와 상태를 합의할 때
- 스크린샷을 구현 중심의 와이어프레임으로 변환할 때
- 화면별 상태와 동작 규칙을 시각적으로 비교할 때
- 제품 요구사항과 기능 명세를 화면 단위로 연결할 때

## Codex에서 사용하기

스킬을 설치한 뒤 다음과 같이 요청할 수 있습니다.

```text
$rddd-screen-design으로 로그인 화면의 개요와 오류 상태 상세 와이어프레임을 만들어줘.
```

또는 스크린샷, UI 코드, 요구사항과 함께 다음 정보를 알려주세요.

- 대상 화면 또는 기능
- 주요 사용자 흐름
- 필요한 상태
- 반드시 유지해야 하는 레이블과 동작
- 결과물을 넣을 문서 경로

## 기본 작업 흐름

1. 현재 Ruca Wiki의 작업 규칙, 스키마, 화면 설계서 관련 formal note를 확인합니다.
2. 요구사항, 기능 명세, 현재 UI 코드, 스크린샷을 확인합니다.
3. 개요 화면, 상세 화면, 상태 비교 중 필요한 시각화 수준을 결정합니다.
4. [`references/wireframe-style.md`](references/wireframe-style.md)의 디자인 토큰과 예시를 확인합니다.
5. `assets/`의 가장 가까운 SVG 예시를 바탕으로 와이어프레임을 작성합니다.
6. 각 번호 콜아웃을 하나의 의미 있는 UI 개념과 설명 표로 연결합니다.
7. 결과 문서에 SVG를 `width="70%"`로 삽입합니다.
8. 검증 스크립트를 실행하고 렌더링 결과를 육안으로 확인합니다.

## 검증

SVG 파일을 하나 이상 인자로 전달해 검증합니다.

```bash
scripts/validate-wireframes.sh path/to/wireframe.svg
```

검증 스크립트는 SVG의 기본 XML 구조와 와이어프레임에 필요한 요소를 확인합니다. 유효성 검증만 통과하는 것으로는 충분하지 않으므로, 결과 SVG를 실제로 렌더링해 텍스트 겹침, 콜아웃 위치, 잘린 영역을 함께 확인해야 합니다.

## 문서 구조 예시

```markdown
## 문서 목적

## 화면 개요

### 화면 ID. 화면 이름

<img src="./images/example.svg" alt="화면 개요 와이어프레임" width="70%" />

| 번호 | 영역 | 설명 |
| ---- | ---- | ---- |
| 1 | 헤더 | 페이지 제목과 주요 동작을 제공한다. |

## 공통 영역 상세

## 화면 상세
```

## 작성 원칙

- 개요에서는 주요 영역을, 상세 화면에서는 의미 있는 컨트롤과 상태를 번호로 표시합니다.
- 레이블과 그 값 또는 컨트롤은 독립적인 동작이 없다면 하나의 항목으로 묶습니다.
- 모든 번호는 정확히 하나의 설명 표 행과 대응해야 합니다.
- 시각적으로 다른 상태는 설명만 추가하지 말고 별도 변형 화면으로 표현합니다.
- 플랫폼 공통 UI는 반복해서 그리지 않고 제품 동작에 필요한 부분만 문서화합니다.
- 정확한 사용자 노출 문자열은 화면 설계 문서에 기록하고, 기능 명세에는 동작 규칙을 기록합니다.
- 기능 규칙은 화면 설계서에 반복하지 않고 `관련 기능 규칙`으로 연결합니다.

## 설치

개인 스킬 저장소를 각 머신의 Codex 스킬 디렉터리에 설치합니다.

```bash
npx skills add https://github.com/neo-rooney/rddd-screen-design
```

이 스킬은 특정 프로젝트의 소스 코드나 설정이 아니므로 프로젝트에 직접 복사하지 않고 개인 스킬로 관리하는 것을 권장합니다.

## 버전 관리

스킬 버전은 Git tag로 관리합니다.

```bash
git fetch --tags origin
git checkout v1.0.0
```

새로운 규칙이나 출력 형식이 추가되면 새 버전 태그를 생성합니다. 기존 태그는 이동하지 않습니다.
